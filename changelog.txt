Changelog
=========

Unreleased
----------
- Add an autonym marker so a language is no longer excluded for want of a name.
  Line 1 of a prayer file is the one field not reproduced from a published
  source, so guessing it would be the single fabricated element in an otherwise
  sourced file. But "cannot confirm the autonym" is not "must invent one": line 1
  may now be exactly [autonym not recorded]. The wording avoids the word
  "verified" in any casing, because the provenance and unverified counters match
  their tokens over the whole file and would otherwise be inflated by it.
  validate.py enforces the marker by exact match (an error, not a warning - the
  construct has no legacy files, so a typo would silently create a second value
  across hundreds of index lines) and reports autonym coverage from line 1.
- Fix three pre-existing defects this change would have tripped over:
  the README count regex could not match a four-digit number written with a
  thousands separator, so the validator would have failed the moment the corpus
  passed 999; NOTICE.md was never opened by the validator, leaving its coverage
  figures to drift silently in the document a rights holder reads; and the
  INDEX.md title still read "Batches 1-3: 300 languages", wrong by 402. The
  title now carries no number, since the count beneath it is generated.
- Batch 7: 12 languages recovered from an over-strict batch-5 filter, taking the
  corpus to 702. That filter rejected any endonym equal to the English name.
  The reasoning holds for names carrying an English qualifier (Central Cagayan
  Agta, Pamplona Atta) but not for single-word names like Tem, Tabo or Warlpiri,
  where the autonym genuinely is the name. The narrower rule keeps the 36
  genuine pseudo-autonyms excluded.
- Batch 6: 85 languages from prose editions, taking the corpus to 690. These
  editions carry no poetry markers, so the narrative introduction to verse 9
  cannot be separated structurally. They are handled as Malayalam was: the
  content of Matthew 6:9 is fixed across translations, so an explicit boundary
  printed there - a colon or opening quotation mark - is the 9a/9b split. Guards
  require a short introduction and a substantial remainder; 38 candidates
  printing no such boundary were left alone, and each generated file records
  where the cut was made.
- Remove two duplicate entries found by a corpus-wide audit: Standard Arabic
  duplicated Modern Standard Arabic under the same ISO code arb, and Standard
  Estonian was byte-identical to Estonian. Macrolanguage-plus-variety pairs
  (Yiddish/Eastern Yiddish, Oromo/West Central Oromo, Quechua and Nahuatl
  varieties) were kept, matching existing practice in the corpus.
- Batch 5: 213 further living languages, taking the corpus to 605. The binding
  constraint on earlier batches was endonyms, not translations - a file cannot be
  written if line 1 would be a guess. Autonyms harvested from Wikipedia's
  Infobox language raised endonym coverage of the remaining pool from 222
  languages to 478, of which 272 also passed the poetry-structure and script
  checks. Filters removed a further 59: 28 whose "autonym" was the English
  exonym verbatim, 15 carrying an English geographic qualifier, 8 that were
  country names leaked from the infobox's states field, 5 collisions, one ISO
  reference name, and azb, which was confirmed earlier this session to be
  mislabelled. Per-file provenance rises to 429 of 605.
- Batch 4: 92 further living languages, taking the corpus to 392. Selected for
  verifiability rather than speaker count, since the ranking data runs out long
  before the supply of published translations does. A language qualified only if
  its edition sets the prayer as poetry and its endonym came from a citable
  source written in the same script as the text.
  Of 1,049 remaining languages with a published New Testament, 222 had a sourced
  endonym; 93 of those had no poetry structure and 17 failed the script check -
  the check that catches a catalogue offering a Telugu-script name for an
  Oriya-script edition. 13 more were dropped because their "endonym" was an
  Indonesian gloss ("bahasa Amarasi") rather than an autonym, and 7 collided with
  languages already in the corpus. Per-file provenance rises to 216 of 392.
- Audit the ten provenance claims that predate this process and whose working
  notes were lost. Chhattisgarhi and Sylheti match their cited editions exactly;
  K'iche' matches its cited edition in every word but one (kaex vs k'aex, an
  ejective-marking variant, now recorded in NOTICE.md); the other seven cite
  editions absent from the open catalogue and could not be reached.
- Fix three defects in scripts/verify_provenance.py found during that audit. It
  compared the several glottal-stop characters as distinct, so a K'iche' text
  written with U+02BC shared almost no words with the same text written with the
  saltillo U+A78C; the fold is now applied only between letters, since at a word
  edge the same character is a quotation mark. It also indexed editions by
  English name alone, so it never saw the Chinese Union Version (filed under
  "Chinese", not "Mandarin Chinese") and found no editions at all for Maori,
  Newari, Odia, Shona or Tok Pisin, which the catalogue names differently.
  Editions are now grouped by ISO code and reachable under every name recorded
  for them. Coverage rises from 57 languages/166 editions to 64/194, which
  surfaced one further exact match, Modern Standard Arabic against the Van Dyck
  translation. All twelve applied claims were re-verified after the fixes.
- Backfill provenance for batches 1 and 2 by verification rather than labelling.
  scripts/verify_provenance.py compares each unsourced file's wording against
  Matthew 6:9-13 in every eBible edition for that language, word for word, and
  records a source only on an exact match. 11 files matched and now carry a
  [Verified from ...] line: Breton, Dutch, Maithili, Mandarin Chinese, Maori,
  Modern Standard Arabic, Newari, Nigerian Pidgin, Odia, Somali, Tibetan, Tok
  Pisin. Per-file provenance rises to 124 of 300. The rest did not match any available published edition,
  mostly because they are liturgical texts rather than Bible translations, and
  were deliberately left unattributed.
- Add Malayalam, which was missing from batches 1 and 2 despite ~37 million
  speakers. Hand-curated: the IRV edition prints the prayer as prose, so the
  narrative introduction to verse 9 was removed and the clauses set out at the
  edition's own punctuation.
- Batch 3 complete (100 of 100): 100 languages with a published New Testament,
  ranked by speakers, each reproduced verbatim from its published edition and
  carrying a [Verified from ...] line. Per-file provenance rises from 11 of 200
  to 112 of 300. Beginning with Northern Thai, Wolaytta, Dyula, Rohingya,
  Makonde, South Bolivian Quechua, Eastern Tamang, Tausug, Kinaray-a, Rakhine,
  Tai Dam, Hawaii Pidgin, Luguru, Tamajaq, Balkan Romani, Vlax Romani.
  Excluded after checking: swh (duplicates Swahili), twi (the repo's Akan is
  already "Akan (Twi)"), and azb, which the catalogue labels South Azerbaijani
  but whose text is Latin-script North Azerbaijani from the Baku Bible Society.
  Deferred: fuv, whose Ajami endonym could not be verified and which overlaps
  the existing Fulani entry.
- Batch 3 begins (5 of 100): Eastern Punjabi, Haryanvi, Central Kurdish,
  Tunisian Arabic and Susu. Selection is by speaker count within the set of
  languages that have a published New Testament, since Ethnologue publishes a
  ranking only to position 200. Each text is reproduced verbatim from its
  published edition via eBible.org and carries a [Verified from ...] line.
- README: record the two line-structure conventions now in the corpus, and why
  batch 3's selection criterion differs from batches 1 and 2.
- validate.py: accept an in-progress language count in README ("**N languages")
  rather than requiring the word "complete".
- Add validate.py: checks the corpus format and regenerates the derived regions
  of prayer/INDEX.md (language list, count, review-flag markers). Verified by
  reproducing the hand-built index byte-for-byte on the pre-change tree.
- Add GitHub Actions workflow running the validator on push and pull request,
  and failing if prayer/INDEX.md is out of date.
- Standardise the 10 [UNVERIFIED] files onto one marker syntax at one position.
  The marker now states which kind of gap it is: "composed, not a published
  translation", "partly composed", or "no text". Banjar's Traditional section is
  published text and now carries [Verified from ...] instead of a blanket flag;
  its doxology note becomes an explicit "omitted rather than composed".
- Add CONTRIBUTING.md: source tiers, the rule against composing scripture
  unmarked, doxology handling, when a distinct Literal rendering is required,
  and the bracket-vs-parenthesis convention.
- Add LICENSE (CC BY 4.0) scoped to the compilation, expressly disclaiming the
  underlying translations, plus NOTICE.md recording corpora relied on, per-file
  copyright statements, provenance coverage and a rights-holder contact.
- README: document the generator command, correct the description of the
  unverified files, and add a Licensing section.
